# PLAN — FUT-офис (EA FC 27, Xbox/консоль)

Цель: офис отделов, который присылает в Telegram подсказки (не автобайер, без входа в EA, без покупки монет).
Образец — `trading_office` (облако, ветка `state`, цепочка нейросетей Gemini → OpenRouter).

## Размещение
- **Облако** — приватный репо `Fetras197/fut_office`, GitHub Actions каждые 30 минут. Состояние — ветка `state` (force-push после прохода, как в trading_office).
- **Телефон** — `~/fetras/fut_bot` остаётся (futbot start, watchdog, Termux:Boot не трогаем). Он — отдел «Аналитик рынка» + приёмник кнопок. Меняется только дополнением: модуль `bot/office_link.py` + две строки в `main.py`.
- **Связь телефон ↔ облако** через GitHub API (токен gitsave уже на телефоне), без git-клона:
  - ветка `phone` (пишет телефон): `phone_feed.json` — зависшие цены и статистика карт, `ledger.json` — нажатия кнопок;
  - ветка `state` (пишет облако): `signals.json` — выданные сигналы (телефону нужны, чтобы записать «Купил»), `watch_request.json` — карты, по которым облако просит свежий снимок рынка.
  - Две ветки, чтобы force-push `state` не затирал данные телефона.
- Один Telegram-бот FUT: облако шлёт сообщения по Bot API, телефон принимает кнопки (long polling; в облаке getUpdates не вызываем — конфликт 409).
- Быстрый перекуп: телефон при сильной зависшей цене запускает workflow через `workflow_dispatch` (токен имеет scope workflow) — не ждёт 30 минут.

## Отделы (модули `office/`)
1. **intel** — разведка. Источники в `sources.yaml` (Telegram t.me/s, YouTube RSS + пересказ Gemini, сайты fut.gg/futbin/sportskeeda/realsport101, Reddit). Каждому — рейтинг точности (старт 0.5, дальше считает бухгалтер). Извлечение: сначала правила (регулярки по ключевым словам и тексту), затем Gemini-цепочка для разбора в JSON {тип, игрок, версия, действие, цена}. Дубли склеиваем по ключу (игрок+тип), уверенность растёт с числом независимых источников. Каждый источник опрашивается не чаще интервала из `sources.yaml` (30–60 мин), ошибки источника не роняют проход.
2. **market** (телефон + читатель в облаке) — Futbin: последние 10 продаж, средняя, 5 лотов, ликвидность. Облако читает `phone_feed.json`, просит свежие снимки через `watch_request.json`. Лимитер и пауза при 403 остаются (gate.py / core.RequestBudget).
3. **sbc** — SBC и прогноз: список SBC с fut.gg/futbin, карты-корм (рейтинги), недельный цикл (пятничные промо, чт/пт — ожидание, вс–пн — рост), поведение цен после промо/TOTW, **журнал прогнозов с проверкой через 1/3/7 дней**.
4. **football** — реальные матчи: ESPN (бесплатно, без ключа) — голы, ассисты, красные, оценки где есть; FPL API — травмы/форма. Кандидаты в TOTW и ин-формы заранее.
5. **risk** — налог 5%, мин. прибыль 500 и 7%, ликвидность, запретные часы 19–21 МСК, пятница после 16:00 МСК, первые 4–7 ч нового промо. Не голосует — накладывает вето.
6. **trader** — сигнал только при согласии ≥ 2 отделов (из intel/market/sbc/football), оценка ≥ 60, ≤ 10 в день, риск-менеджер разрешил. Формат сигнала по ТЗ, кнопки.
7. **accountant** — кнопки «Купил / Не нашёл по цене / Продал за…», прибыль, точность по отделам и источникам, воскресный совет с понижением плохих источников.

## Карточки и цены
- Имя игрока → карта: поиск fut.gg (`/players/?name=`), цены всех карт из публичных r2-файлов fut.gg (переиспользуем парсеры futbin_mcp/sources.py).
- Свежесть: перед отправкой сигнала облако перепроверяет цену по r2 fut.gg; цена выше «Купить до» — сигнал снимается.

## Нейросети
`office/llm.py` — копия цепочки trading_office (Gemini с дневным бюджетом, затем OpenRouter: бесплатные модели → платная под потолок 0,20 $/сутки → Groq/Cerebras/Mistral). Ключи только в Secrets. Без ключей работает режим «только правила».

## Тексты
Все сообщения — правильный русский, без кодов и английских слов. Модуль `office/ru.py` — словарь названий (промо, типы), склонения «монета/монеты/монет», проверка `no_latin()` в тестах; LLM-тексты прогоняются через ту же проверку, при провале используется шаблон.

## Этапы (после каждого — тесты, отчёт, DECISIONS/PROGRESS)
1. Каркас: репо, БД, конфиг, llm, telegram, workflow, ветки state/phone, `sources.yaml`.
2. Разведка по каналам (+YouTube, сайты, Reddit), склейка дублей, рейтинг источников.
3. SBC/прогноз + футбольный аналитик.
4. Риск, трейдер, формат сигнала, кнопки (облако — отправка, телефон — приём).
5. Бухгалтер и воскресный совет.
6. Живая проверка 2 часа: доля сигналов, где карта реально лежит по цене «Купить до» (проверка по свежим данным телефона через 0 и 10 минут после сигнала), цель ≥ 70%.

## Риски
- Futbin режет облачные IP → всё Futbin только на телефоне; облако ходит на fut.gg r2, ESPN, YouTube, t.me.
- Sportskeeda отвечает 403, Reddit 403 → пропуск без ошибки.
- Бюджет Futbin 40 запросов/час на телефоне: облако просит ≤ 8 карт за проход.
- Минуты Actions: приватный репо 2000/мес; проход ≤ 3 мин × 48/сутки ≈ 4300 мин/мес — **не влезает**. Решение: расписание */30 только с 09:00 до 23:00 МСК (30 проходов × ~2 мин ≈ 1800 мин/мес), ночью раз в 2 часа; сначала измерить длительность прохода.
- Нет реального способа проверить цену «на рынке EA» без входа в аккаунт: проверяем по Futbin/fut.gg (ограничение зафиксировать в отчёте).
