# DECISIONS — FUT-офис

- 2026-10-21 D1. Репозиторий `Fetras197/fut_office` (приватный), код в `~/projects/fut_office`. Телефонный бот `fetras/fut_bot` не переписываем: добавляем модуль `bot/office_link.py` (передача данных, приём кнопок).
- D2. Ответ Gemini на план (gemini-plan, 2026-10-21):
  - Принято: строгая проверка JSON от нейросети (схема, допустимые значения, цена в разумных пределах, игрок должен найтись в базе fut.gg) — иначе факт отбрасывается; рассинхронизация сигналов — у каждого сигнала номер, кнопки хранят номер, облако повторно не шлёт сигнал с тем же ключом (карта+тип) 6 часов; перед отправкой цена перепроверяется по ленте fut.gg.
  - Отклонено: «заменить ветки GitHub на Supabase/Firebase» — ТЗ требует ветку state и GitHub; лаг устранён тем, что у каждой стороны свой файл-писатель (облако — ветка state, телефон — ветка phone), общих записей нет. «Весь скрапинг на телефон» — облако читает только открытые источники, где блокировок нет (t.me/s, YouTube RSS, fut.gg, ESPN); Reddit, Sportskeeda — пропуск без ошибки. Futbin с облака не трогаем вообще — только телефон.
  - Принято к сведению: задержка до 30 минут для «быстрого перекупа». Смягчение: телефон при сильной зависшей цене запускает облако вне очереди (workflow_dispatch), а перед отправкой цена перепроверяется.
- D3. Минуты GitHub Actions: у аккаунта общий лимит 2000 мин/мес на все приватные репозитории (trading_office тоже тратит). Расписание: каждые 30 минут с 08:00 до 22:00 МСК, ночью раз в 2 часа. Каждый проход обязан укладываться в ~1 минуту (кэш pip, минимум зависимостей).
- D4. Имена игроков остаются латиницей (так они написаны в игре и нужны для поиска карты); всё остальное — по-русски. Проверка `ru.no_latin` в тестах игнорирует поле имени игрока.
- D5. «Xbox» = консольная цена fut.gg/Futbin (у них единый консольный рынок). Отдельной цены Xbox нет.
- D6. Канал «FUT Reveal»: точный адрес хаба неизвестен (проверены futreveal, FUT_Reveal, futrevealhub и др. — открытой ленты t.me/s нет). В sources.yaml стоит `enabled: false` с пометкой; владелец может дописать ник.
- D7. X (Twitter) не подключаем (по ТЗ). Reddit r/EASportsFC с облака отдаёт 403 → источник пропускается молча, пауза 6 часов.
- D8. Рейтинг источника: старт 0,5; считает бухгалтер как сглаженную долю подтверждённых фактов (байесовская поправка, не меньше 5 проверок для понижения). Понижение «плохих» (< 0,35 после ≥ 8 проверок) — воскресный совет.
- D9. «Согласие двух отделов» = два разных отдела из (разведка, рынок, SBC-прогноз, футбольный аналитик) дали голос «покупать» по одной карте. Риск-менеджер не голосует, а накладывает запрет.
- D10. Проверка «игрок по цене»: в момент отправки и через 10 минут цена карты в ленте fut.gg (r2, обновляется раз в 3–5 минут) сравнивается с «Купить до». Это доступная без входа в EA проверка; прямой рынок EA недоступен по условию «без входа в аккаунт» — ограничение зафиксировано в отчёте.
